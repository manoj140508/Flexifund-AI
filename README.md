# FlexiFund AI

> “When your income changes, your financial plan should change with it.”

FlexiFund AI is a production-grade financial resilience platform engineered for gig workers and individuals with irregular incomes (delivery workers, ride-hailing drivers, freelancers, daily-wage contractors, and independent service providers).

---

## Core Product Principle

```
REAL USER DATA
      ↓
VALIDATION & NORMALIZATION
      ↓
DETERMINISTIC FINANCIAL ANALYSIS
      ↓
OPPORTUNITY DETECTION
      ↓
SCHEME / POLICY MATCHING
      ↓
PRIORITIZATION
      ↓
PERSONALIZED RECOMMENDATIONS
      ↓
OPTIONAL AI EXPLANATION
```

The financial analysis, resilience calculations, and scheme matching are **100% deterministic** and do not rely on language models.

---

## Non-Negotiables & Guarantees

1. **Integer Minor Currency Units:** All monetary arithmetic uses integer `paise` (1 INR = 100 paise) internally to eliminate floating-point calculation errors.
2. **Current Cash Buffer Transparency:** We never confuse historical transaction surplus with actual current bank balance. The user can optionally supply their current available cash buffer; otherwise, metrics are clearly labeled as historical estimates.
3. **Traceable Evidence:** Every single metric, opportunity, warning, or recommendation retains a direct pointer to the originating transactions or profile attributes.
4. **No Hallucinated Schemes:** Every welfare program in the catalog has been verified against published official government portals.
5. **Privacy First:** No banking credentials, passwords, PINs, OTPs, or CVVs are ever requested or stored.

## Getting Started

### Prerequisites
- Node.js `20.x` or `24.x`
- npm `10.x` or `11.x`

### Installation
```bash
npm install
```

### Running Tests
```bash
npm run test
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
